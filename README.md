# Wael Fathy - Portfolio (phone-friendly flat version)

All files are loose at the root - no folders - so you can upload everything
from your phone in one go.

## Publish on GitHub Pages from your phone
1. Create the repository: name it exactly `waelfathy27.github.io`, Public,
   no README, no .gitignore, no license.
2. Tap "uploading an existing file".
3. Select ALL the files in this folder (28 files) and commit.
4. If the site is not live after a few minutes: repo Settings > Pages >
   Deploy from a branch > main > /(root) > Save.

Live at https://waelfathy27.github.io after a minute or two.

## Local preview
Open index.html in any browser - everything works offline.
